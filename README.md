# TODO-планировщик задач

Веб-сервер для управления задачами с поддержкой повторяющихся событий. Дипломный проект.

## Функциональность

- Создание, редактирование, удаление задач
- Отметка о выполнении задачи
- Повторяющиеся задачи с поддержкой правил:
  - y - ежегодно
  - d N - через N дней (N от 1 до 400)
  - w 1,3,5 - по дням недели (1 - понедельник, 7 - воскресенье)
  - m 1,15,-1 - по дням месяца (отрицательные значения - с конца месяца)
  - m 1,15 1,6,12 - по дням в конкретных месяцах
- Поиск задач по заголовку, комментарию или дате (формат DD.MM.YYYY)
- REST API

## Запуск

### Установка зависимостей

go mod tidy

### Запуск сервера

go run main.go

Сервер будет доступен по адресу: http://localhost:7540

### Переменные окружения

- TODO_PORT - порт для запуска сервера (по умолчанию 7540)
- TODO_DBFILE - путь к файлу базы данных (по умолчанию scheduler.db)

Пример запуска с переменными:

TODO_PORT=8080 TODO_DBFILE=/tmp/tasks.db go run main.go

## Тестирование

go test ./tests -v

## API Endpoints

| Метод | URL | Описание |
|-------|-----|----------|
| GET | /api/tasks | Получить список задач (поддержка ?search=) |
| POST | /api/task | Создать задачу |
| GET | /api/task?id= | Получить задачу по ID |
| PUT | /api/task | Обновить задачу |
| DELETE | /api/task?id= | Удалить задачу |
| POST | /api/task/done?id= | Отметить задачу выполненной |
| GET | /api/nextdate | Вычислить следующую дату выполнения |
